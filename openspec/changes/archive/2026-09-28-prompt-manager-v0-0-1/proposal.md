## Why

日常从网络上收集到的长提示词现在散落在帖子和备忘里，过后想再找到某一条、并想起当初为什么收录它，没有一个固定的地方。先做一个只负责收下、找回和回看的个人库，生成和建议等以后的能力才有原文可依。

## What Changes

- 新增一个本地、单人的提示词库。收录方式是用户自己贴上整段原文，系统不负责从页面抓取提示词。
- 每条提示词保存完整原文，以及最多一个可选的 example URL。链接指向当初那个作品（帖子、网页或视频），用来记住为什么收录它。
- 用户可以列出已保存的提示词、打开阅读全文、按原文中的字句搜索、改正已保存的内容和链接、删除一条提示词。
- example URL 以链接展示，由用户在浏览器中打开。系统不抓取、不预览、不检查链接是否还能访问。
- 搜索匹配粘贴原文中的连续字句，包含中文和英文，不依赖分类或标签。
- 本版不做分类、标签、按意思搜索、按需求生成提示词、对提示词提建议，也不顺着链接检查效果。

## Capabilities

### New Capabilities

- `prompt-library`: 保存、查看、搜索、改正和删除用户贴入的提示词，并为每条提示词保留一个可选的 example URL。

### Modified Capabilities

- 无。仓库里还没有既有能力规格。

## Impact

- 仓库目前没有应用代码。本变更会从零加入本地存储、一个本机页面，以及围绕提示词原文和 example URL 的读写。
- 不引入账号、同步、远程服务或模型调用。
- 不影响既有系统；没有需要迁移的数据。
