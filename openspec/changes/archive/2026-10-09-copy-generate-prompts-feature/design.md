## Context

本机页面由 `internal/web` 渲染，线上同一套交互在 `cloudflare/src/app.mjs`。列表条目只有约 120 字的摘要；`created_at` 已按 UTC 存在 `prompts` 里，改正原文不会改它，页面还没显示。详情全文在 `<pre class="body">` 里，经转义后展示。搜索先找字面命中，再对其余已就绪的当前版本做语义检索；短查询会抬高相似度门槛。语义检索走 Astra 的 `vector.Backend.Search`，没有向量后端时退回进程内余弦。

Cloudflare 的 CSP 是 `default-src 'none'`，没有 `script-src`。本机页面没有 CSP。现有测试把整页出现 `<script` 视为提示词正文被执行。抽词和嵌入的端点在 `./data/config.json` 的 `term` 与 `embed`，线上是同结构的 `APP_CONFIG`。见 `proposal.md`。

## Goals / Non-Goals

**Goals:**

- 复制和日期在本机与 Cloudflare 上行为一致，提示词正文仍只作为文字出现。
- 选范例是一条独立于搜索页的检索：整句嵌入、普通相似度门槛、最多 3 条、不因字面命中而排除。
- 草稿只活在「贴上一条」这次响应里。入库仍只走现有的保存函数。

**Non-Goals:**

- 在详情页显示添加日期，或在保存后标记这条来自生成。
- 记住需求、提供「再生成」，或让用户勾选范例。
- 改搜索规则、派生规则、表结构，或给线上站点加登录。
- 把整库全文放进一次写作请求。

## Decisions

### 复制用一段同源脚本，正文放在转义后的文本框里

`GET /copy.js` 返回一段固定脚本。列表、搜索结果、详情的每条复制按钮指向同一条目里的隐藏只读 `textarea`，里面是库存全文。脚本只读这个文本框的值，调用 `navigator.clipboard.writeText`。成功把按钮写成 `已复制`，失败写成 `没复制成`。文本框由现有转义写入，不用 `innerHTML`。

Cloudflare 的 CSP 增加 `script-src 'self'`，其余指令不变。本机页面继续不加 CSP，因为样式是内联的；脚本同样从本源的 `/copy.js` 加载。`bottom.html` 引入这个脚本。

备选是内联脚本。它会迫使 CSP 使用 `unsafe-inline` 或哈希，并且和「整页不得出现 script 标签」的现有测试缠在一起。固定文件更容易核对脚本没有解析提示词。

含 `</textarea>` 或 `<script>` 的原文必须被转义，不能提前结束文本框。现有「整页查找 `<script`」的断言要改成只检查提示词正文区域，同时仍要求正文里的 `<script>` 以转义文字出现。

### 添加日期在服务端按北京时间格式化

列表和两类搜索结果都输出 `添加于 YYYY-MM-DD`。用 `Asia/Shanghai` 把 `created_at` 转成日历日，不在浏览器里换时区，测试可以直接看 HTML。`2026-09-28T16:00:00Z` 显示 `2026-09-29`，`2026-09-28T15:59:59Z` 显示 `2026-09-28`。详情页不增加这一行。

### 写作端点单独配置，调用与抽词分开

`data/config.json` 和 `APP_CONFIG` 增加：

```json
"draft": { "baseUrl": "", "apiKey": "", "model": "" }
```

`baseUrl` 留空时仍是 `https://openrouter.ai/api/v1`。API key 和 model 没有默认值，也不从环境变量读取。`derive.Config` 增加对应字段和 `DraftReady`。未就绪时 `POST /prompts/draft` 不发写作请求，页面显示 `还不能生成`。

写作是 `POST {baseUrl}/chat/completions`，读取完成消息的 `content`，只去掉首尾空白。这是 `Config` 上的新方法，不复用 `Extract`：抽词要求 JSON 词条，写作要求一份提示词正文。失败原因沿用现有脱敏，Cloudflare 的 `redact` 把 `draft.apiKey` 也列入。日志只记需求的字符数、范例条数和耗时，不记需求原文。

系统消息要求：只输出一份提示词；题材是用户这次的需求；范例只示范写法，不搬用范例的题材；按需求所用的语言来写。用户消息里先放需求，再放选中的全文，并标明那是写法范例。不发送示例链接。

备选是复用 `term` 的模型。抽词模型和写作模型经常不是同一个，所以单独一块配置。

### 范例检索不走搜索的 Match

新检索把需求整句嵌入一次，可以复用现有查询向量缓存。门槛用 `similarityMin`，不用 `queryMinimum`。候选是已有当前版本向量的提示词，包含那些字面也能命中的条目。按最高相似度取前 3 条。上限是常数 3，不用 `meaningLimit`，因为这里送的是全文，而库里已有约 3500 字的提示词。

本机有 Astra 时调用 `vector.Backend.Search`，传入全部就绪版本。没有向量后端时，用现有的进程内余弦，对全部文档打分后取前 3。Cloudflare 调用现有 `meaningSearch`，候选是全部 `derive_status = ready` 的当前提示词，门槛和上限按上面的规则传入。

嵌入未配置、嵌入失败，或没有条目过线时，范例为空，写作仍然进行。保存页同时显示 `这是生成的草稿，改完再保存` 和 `这次没有参考`。有范例时只显示前一句。

### 草稿页和保存页分开，路由使用固定路径

页头在「贴上一条」旁增加「写一条」。

- `GET /prompts/draft` 显示需求框，按钮是 `生成`。
- `POST /prompts/draft` 在成功时渲染现有的新提示词表单，动作为 `POST /prompts`，正文字段是草稿，示例链接为空。
- 需求为空时停在草稿页，显示 `要写的内容必填`。
- 写作失败或返回空白时停在草稿页，保留需求，显示 `没有生成出来`。
- 成功响应不调用 `store.Create`，也不排进派生队列。用户之后提交「贴上一条」才走现有保存和派生。

`/prompts/draft` 必须注册成固定路径，避免被 `GET /prompts/{id}` 当成一条不存在的提示词。Cloudflare 用同样的路径判断。取消草稿沿用现有表单的取消，回到库列表，不写入。

## Risks / Trade-offs

- [线上任何人都能触发生成，并让写作模型读到最多 3 条全文] → 与现在的公开读写、以及派生时把原文送去模型是同一边界。本变更不加登录。请求只带过线的 3 条，不带示例链接。
- [模型仍可能把范例题材写进新稿] → 请求里把需求写成题材、把旧稿写成写法范例。结果先进入编辑框，不自动入库。
- [剪贴板在非安全来源或不授权时失败] → 本机是 `127.0.0.1`，线上是 https。失败时按钮显示 `没复制成`，不改库。
- [`script-src 'self'` 放行本源脚本] → 只增加固定的 `/copy.js`，不提供上传脚本的路径。脚本不解析页面中的提示词 HTML。
- [列表 HTML 带上全文，页面变大] → 当前库是个人规模。本变更不做分页。
- [未归档的 `multi-lang-support` 已让搜索在字面命中之外仍显示其他「意思相近」] → 范例检索不调用搜索的 `Match`。字面命中的提示词只要相似度够，仍然可以成为范例。

## Migration Plan

不改表，也不回填日期。旧的配置文件没有 `draft` 时，复制和日期可用，生成显示 `还不能生成`。线上更新代码后再把 `draft` 写进 `APP_CONFIG`。回滚到旧程序后，复制、日期和「写一条」消失；已保存的提示词不受影响，未保存的草稿本来就不在库里。
